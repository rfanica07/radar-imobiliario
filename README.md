# Radar Imobiliário — Lisboa e Setúbal

Aplicação de prospeção imobiliária com 20 zonas, mapas, números de polícia, prédios, andares e frações. Inclui registos independentes de flyers e bate-porta e sinalização de prédios com frações por contactar.

## Experimentar

Abre `index.html` num navegador atualizado ou publica a raiz no GitHub Pages. A aplicação não precisa de instalação nem de compilação. No telemóvel podes adicionar o endereço ao ecrã principal através do menu do navegador.

## Guardar os teus dados

Os registos ficam no armazenamento local de cada navegador. Não existe sincronização automática entre aparelhos. Usa **Exportar** no aparelho de origem e **Importar** no destino. Ao passar do ficheiro local para um endereço HTTPS, exporta primeiro os registos existentes. Limpar os dados do navegador pode apagar os registos locais.

## Fontes e cobertura

Consulta `Fontes-e-cobertura-das-portas.md`. Os números importados da Moita/Baixa da Banheira incluem o inventário histórico do INE de 2018 e podem exigir confirmação no terreno. Os indicadores imobiliários têm datas e fontes próprias; não constituem informação de mercado em tempo real.

## Atualizações

O `index.html` inclui os scripts e os dados cartográficos necessários. As próximas versões podem substituir os ficheiros mantendo o mesmo endereço. O código modular foi preservado no arquivo de fontes. Os dados pessoais de prospeção não fazem parte deste repositório.
